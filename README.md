Medicine Reminder

A simple medicine reminder app that helps users manage medicine schedules with date, time, search, status tracking, and reminder sounds.

Features

- Add medicine reminders
- Edit reminders
- Delete reminders
- Set reminder date and time
- Morning, Afternoon, and Night options
- Search and filter reminders
- Mark reminders as Taken
- Reminder sound
- Saves reminders using localStorage

Technologies Used

- HTML
- CSS
- JavaScript
- Browser Local Storage
- Web Audio API
